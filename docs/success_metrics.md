# Success Metrics

To objectively evaluate the Beta test, we will track the following Key Performance Indicators (KPIs). These metrics separate emotional feedback from actual behavioral data.

## 1. Progression Metrics
- **Completion Rate:** The percentage of users who complete all 7 lessons of a language curriculum. *(Target: >70%)*
- **Lesson Drop-off:** The specific module (e.g., Speaking, Typing, Quiz) where users are most likely to abandon a lesson mid-session.
- **Average Lesson Time:** The time taken from the first `knowledge_card` to the `celebration` module. *(Target: 5–8 minutes)*

## 2. Retention Metrics
- **Daily Return Rate:** The percentage of users who return to complete a lesson on consecutive days.
- **Day 7 Retention:** The percentage of users still actively engaging with the platform one week after onboarding.
- **User Satisfaction (NPS):** Gathered via the end-of-beta survey. *(Target: >8.0/10)*

## 3. Educational Efficacy Metrics
- **Mistake Rate:** The average number of errors logged to the `Mistake Notebook` per lesson. If this is too low, the content is too easy. If too high, cognitive load is exceeded.
- **First-Try Quiz Pass Rate:** The percentage of users who complete the Final Quiz without failing a question on their first attempt.

## 4. Technical Engagement Metrics
- **Audio Usage:** The percentage of lessons where users actively engage with the "Play Audio" buttons instead of muting their device.
- **Speech Usage:** The percentage of users attempting the Voice Recognition modules versus those who skip or fail them due to browser constraints.
