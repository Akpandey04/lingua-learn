# LinguaLearn Content Authoring Rules

This document serves as the "Bible" for generating lessons across all languages in LinguaLearn. Any content generated by scripts or authored manually **MUST** adhere to these rules.

## 1. Lesson Structure
Every standard learning lesson MUST follow this progression format to ensure pedagogical consistency:
1. **Objectives**: Explicitly state what the learner will accomplish.
2. **Vocabulary**: Introduce the new concepts as flashcards.
3. **Pronunciation**: Explicitly teach pronunciation mapping.
4. **Listening**: Audio identification of new concepts.
5. **Speaking**: Speech recognition practice of the concepts.
6. **Dialogue**: A conversational scenario utilizing the new vocabulary naturally.
7. **Reading**: Text comprehension checking.
8. **Writing**: Typing out answers or translating.
9. **Practice**: Mixed interactive exercises (matching, MCQs).
10. **Summary**: Recap of the concepts learned.
11. **Quiz**: Final assessment of the lesson's material.
12. **Celebration**: XP/Completion screen.

*(Note: Not every module type is fully implemented in V1. For V1, map this flow using the available modules: `vocabulary`, `dialogue`, `quiz` (with practice exercises mixed in), and `knowledge_card`).*

## 2. Pacing & Progression
- **5-10 Concepts Maximum**: Never introduce more than 10 new concepts per lesson.
- **Natural Reinforcement**: Dialogues must reuse vocabulary from previous lessons to build spaced repetition.
- **No Grammar in Review**: Review lessons must exclusively test previously learned material, introducing zero new concepts.

## 3. Modular Architecture (Data vs Structure)
- **Do NOT duplicate concepts**: "Bonjour" should only exist once as `concepts/french/greeting_hello.json`. Lessons reference it by ID (`greeting_hello`).
- **Grammar Library**: Grammar concepts (e.g., Articles, Present Tense) live in `grammar/{language}/` (similar to concepts) and are referenced by ID.
- **Browser TTS**: Use `SpeechSynthesis` for audio (`audioText`). Do NOT create fake mp3 placeholder URLs.

## 4. Concept Richness
Every vocabulary concept MUST have:
- `native`: The target language word/phrase.
- `translation`: English equivalent.
- `ipa`: Phonetic spelling.
- `pronunciation`: Beginner-friendly phonetic guide (e.g., "Bon-zhoor").
- `exampleSentence`: A contextual usage example.
- `exampleTranslation`: English translation of the example.
- `memoryTip`: A mnemonic or logic tip to help remember it.
- `difficulty`, `cefr`, `tags`.

## 5. Review & Checkpoints
- Every unit MUST end with a **Review Lesson** mapping to concepts learned in that unit.
- Every unit MUST conclude with a **Checkpoint Conversation** (Dialogue-heavy roleplay testing all concepts).

## 6. Technical Requirements
- No duplicate React keys (e.g., always use `id-optionIndex`).
- No duplicate IDs across the entire curriculum.
- Consistent folder structure (`content/{language}/{level}/{unit-id}/{lesson-id}/lesson.json`).
- Ensure valid JSON and strict adherence to the `types/domain.ts` schemas.
